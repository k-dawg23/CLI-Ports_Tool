# v2.0.2 acceptance-review remediation

Local verification date: 2026-11-07. This report covers the two defects identified by the focused acceptance review. No commit, push, tag, or release was performed.

## Confirmed defects and root causes

1. **Old Windows cwd restored after a metadata deadline.** The service registered cache deletion only after awaiting optional process preparation. When preparation exhausted the deadline, `CollectionContext.stage()` rejected that deletion. Windows also retained its old global process entry because the replacement metadata never completed. A subsequent collection with failed process/CIM queries had no new invalidation marker and reused the old service cwd. The reproduced sequence was `/old`, unavailable, then `/old` again.
2. **Replacement tests used POSIX path expectations on Windows.** The mocked command lines used `/old/server.js` and `/new/server.js`, but production derives cwd with platform-native `path.resolve()` and `path.dirname()`. Literal `/old` and `/new` assertions were therefore incorrect on Windows.

## Corrections and regression coverage

- The service now registers invalidation publication before optional process preparation. The staged callback reads the collection's completed invalidation set at publication, so a later optional metadata deadline does not lose a successfully observed identity change. Failed required collections still call `finish(false)` and discard staged writes.
- Windows stages deletion of its previous process entry immediately upon detecting different valid start times, before awaiting CIM metadata. Replacements remain staged, and late completion cannot publish through a closed context.
- Path expectations now use the same platform-native resolution as production.
- The deadline regression now exercises four collections: initial cwd, replacement plus deadline, failed process/CIM refresh, and successful recovery. It also completes the timed-out query late and verifies that neither the old cwd nor late data is published. Listener addresses and warnings remain asserted.

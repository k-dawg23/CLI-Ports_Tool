# v2.0.1 launcher locale remediation

Date: 5 November 2026.

Status: Corrected and locally verified on Linux. Version remains 2.0.1. Nothing was committed, pushed, published, or released.

## Cause and focused correction

`runCheckedCommand` unconditionally supplied `env: { LC_ALL: "C" }`. Editor and browser launches reused that runner, so its system-command locale normalization overrode the user's locale even after launcher timeouts were disabled.

Added one optional `inheritLocale` flag to the existing command options. Its default preserves the existing normalized C locale. Only the four editor/browser launch calls in the Unix and Windows backends opt in; those calls omit the locale override and inherit the parent environment normally. They continue to use `timeoutMs: 0`.

Production changes are confined to `src/system.ts`, `src/backends/unix.ts`, and `src/backends/windows.ts`. There is no general environment configuration API, custom environment map, dependency change, or redesign. Editor selection, launch arguments, error handling, and public output are unchanged.

## Regression coverage

The new tests first reproduced the inherited locale being replaced by `C`. After correction, all six new regression tests pass:

- All four Unix/Windows editor/browser launch paths preserve explicit, absent, and empty `LC_ALL`, plus `LANG`, `LC_MESSAGES`, `LANGUAGE`, and an unrelated test environment variable. GUI executables are replaced with harmless Node probes that use the real checked runner; no real browser or editor is opened.
- Default system-command execution still normalizes `LC_ALL` to `C`, preserves other variables, and leaves the parent's environment untouched.
- Explicit timeouts and cancellation work with either locale policy, including cancellation after an owned Node fixture confirms startup.

Existing launcher assertions now check locale inheritance. Stop-command assertions confirm that termination does not opt in and retains its 15-second bound. The existing 16-second editor lifetime test, discovery/deadline tests, termination sequence tests, and guarded native ownership tests also pass.

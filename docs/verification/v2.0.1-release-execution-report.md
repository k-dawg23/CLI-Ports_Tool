## 6. Deviations, diagnosis and retries

### Windows post-merge timeouts

Both initial post-merge native checks timed out the first spawned list --json at approximately 15,025/15,020 ms with no output. The native wrapper's overall deadline equaled the application's 15-second active collection budget, leaving no allowance for startup, scheduling, output or child cleanup.

After explicit renewed approval, commit 9ccdd9a gave spawned native-test CLI invocations a 30-second outer observation window and retained elapsed time, exit status, stdout and stderr. Other helper limits and the production collection budget remain 15 seconds; all discovery-success assertions, command policies and ownership safeguards remain unchanged.

The corrected main run passed. Later initial Windows list calls took 10,074 ms on corrected main, 12,972 ms on the tag-push run and 6,954 ms on the final fresh run, all with valid output/exit 0. These measurements do not prove why the original invocations exceeded 15 seconds. They demonstrate passing current behavior; the observation-window design was corrected without claiming an unproven underlying Windows cause or masking an application diagnostic.

### macOS tag-run observation race

Tag-push run 42241835709 passed feasibility but failed the immediate raw-mode assertion after the first TUI frame. Its own observation log then records actual raw mode successfully enabled, followed by the harness-triggered abort. This confirms a readiness-observation race, not inability of the product to enable raw input. Its owned fixtures exited and PTY child/descriptors were cleaned up.

Publication stopped and renewed approval was obtained. The user approved exactly one fresh full run on the unchanged tag, with publication conditional on success. Run 42245636836 passed and its actual artifacts were inspected before publication. No assertion was weakened, candidate replaced, tag retargeted or failed record discarded.

A bounded-readiness-wait proposal remains unapplied at raw-readiness-draft.patch. It is a future verification-infrastructure follow-up, not a hidden modification to this released tag.
